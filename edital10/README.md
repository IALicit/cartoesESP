# Cartões-Resposta — Edital nº 10/2026 (ESP/CE)

Portal de consulta dos cartões-resposta dos **candidatos presentes** (38).
O candidato consulta por **número de inscrição** ou **CPF** e visualiza/baixa o próprio cartão.

- `index.html` — página de consulta
- `cartoes.js` — mapeamento inscrição/CPF → arquivo do cartão
- `candidato_001.pdf` … `candidato_038.pdf` — cartões individuais

Hospedado via GitHub Pages, na subpasta `edital10/` do repositório `cartoesESP`.
Link (após upload): https://ialicit.github.io/cartoesESP/edital10/
