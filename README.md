# Cartões-Resposta — Edital nº 09/2026 (ESP/CE)

Portal de consulta dos cartões-resposta dos **candidatos presentes** (106).
O candidato consulta por **número de inscrição** ou **CPF** e visualiza/baixa o próprio cartão.

- `index.html` — página de consulta
- `cartoes.js` — mapeamento inscrição/CPF → arquivo do cartão
- `candidato_001.pdf` … `candidato_106.pdf` — cartões individuais

Hospedado via GitHub Pages. Link: https://ialicit.github.io/cartoesESP/
